# Doris SQL 参考提炼

## SQL 手册结构

SQL 手册主要分为：

- 基础元素：字面量、标识符、关键字、操作符和数据类型。
- SQL 函数：聚合函数、标量函数、表函数、表值函数、窗口函数、组合器和 AI 函数。
- SQL 语句：账号管理、Catalog、集群管理、数据修改、数据库、函数、Job、插件、回收、安全、会话、统计信息、表/视图、事务和系统帮助。

撰写或审查 SQL 文档时，将语法和示例视为契约级内容。不要编造语法或默认值。

## 语法约定

- SQL 关键字使用大写。
- 用户提供的对象使用 `<angle_bracket>` 占位符。
- 可选子句使用方括号。
- 备选项使用花括号和竖线：`{ A | B }`。
- 只有可重复结构使用省略号。
- 正式语法放在 `sql` 代码块中。
- 如果 SQL 语句有主要变体，应在清晰的小节下分别说明。

## 函数族

### 聚合函数

包括通用聚合、统计函数、Bitmap/HLL/Quantile 聚合、数组/列表收集、协方差/相关性，以及排名类聚合辅助函数等。

常见审查点：

- 说明 NULL 输入是被忽略、返回 NULL，还是导致 NULL。
- 适用时说明是否支持 DISTINCT。
- 对近似函数，说明近似语义和输出类型。
- 对状态类函数，说明输出是中间状态还是最终标量值。

### 标量函数

主要类别：

- 数组函数：转换、过滤、类 reduce 操作、元素查找、distinct/except/intersect、排序、枚举、数组内聚合。
- Bitmap 函数：创建、转换、基数、布尔操作、包含判断、最小/最大值、子集类检查。
- 日期时间函数：日期运算、截断、提取、格式化、取整、Unix 时间转换、时区转换。
- 字符串函数：拼接、拆分、裁剪、大小写、正则、URL/域名提取、脱敏、编码、压缩、查找替换。
- JSON 函数：提取、路径存在性、修改、数组/对象、长度、键、解析/引用、转换。
- 数值和数学函数：算术、取整、三角函数、对数、随机数、进制转换。
- IP 函数：IPv4/IPv6 转换、CIDR 范围、包含判断、字符串校验、默认值/NULL 变体。
- 加密和摘要函数：AES/SM4 加解密、MD5/SHA/SM3 哈希、CRC、MurmurHash、XXHash。
- Map 和 Struct 函数：构造、键、值、条目、元素访问、大小、包含判断。
- 空间函数：几何对象构造、关系判断、距离、面积、长度、WKT/WKB 转换。
- 条件函数：`IF`、`IFNULL`、`NULLIF`、`COALESCE`、`GREATEST`、`LEAST`、NULL/空值辅助函数。
- 系统函数：当前 Catalog/Database/User/Session 信息、连接 ID、版本、最后查询 ID。
- Variant 函数：动态 JSON 类值检查和元素访问。

标量函数示例应覆盖类型转换行为、边界输入、相关时的多字节字符串行为，以及 NULL 处理。

### 表值函数和表函数

表值函数用于暴露生成行、文件、元数据、本地/HTTP/HDFS 源、查询信息、BE/FE 元数据、分区、Catalog、Job 和外部表元数据。

应说明：

- 调用语法。
- 必需属性。
- 返回列。
- 权限和安全影响。
- 外部路径、文件格式、凭证或网络约束。

### 窗口函数

常见函数包括 `ROW_NUMBER`、`RANK`、`DENSE_RANK`、`NTILE`、`LAG`、`LEAD`、`FIRST_VALUE`、`LAST_VALUE`、`CUME_DIST` 和 `PERCENT_RANK`。

应说明：

- 必需的 `OVER` 子句形式。
- 分区和排序行为。
- 适用时说明窗口框架敏感性。
- 并列值如何处理。
- `lag`/`lead`/默认值相关的 NULL 处理。

## SQL 语句类别

### 账号与安全

包括用户、角色、授权、权限、LDAP 密码/管理员设置、密码修改、行策略、SQL Block Rule、加密密钥和文件。

审查重点：

- 权限对象作用域。
- 执行所需权限。
- 安全敏感默认值。
- 操作影响内部用户、LDAP 用户还是外部集成。

### Catalog

包括创建、修改、删除、显示和刷新 Catalog。External Catalog 文档必须覆盖：

- Catalog 类型。
- 必需属性。
- 可选属性和默认值。
- 元数据映射和缓存行为。
- 谓词/函数下推支持和限制。
- 权限。
- 外部系统凭证、驱动和安全影响。

### 集群与工作负载管理

包括 Resource、Backend、Broker、FE Follower/Observer、计算组、Workload Group、Workload Policy 和集群级检查命令。

审查重点：

- 语句适用于存算一体还是存算分离架构。
- 是否改变集群成员或调度行为。
- 所需端口或 endpoint 格式。
- 高可用影响和运维风险。

### 数据修改与导入

包括 `INSERT`、`INSERT OVERWRITE`、`UPDATE`、`DELETE`、`MERGE INTO`、备份/恢复、Repository、Load Job、Routine Load、事务语句和导入相关状态命令。

审查重点：

- 支持的表模型。
- 事务语义。
- 部分列更新行为。
- 删除/更新限制。
- Label、Job 状态、错误处理和可见性。

### 表与视图

包括创建、修改、删除、显示 Table/View/Materialized View，分区、索引、Rollup、副本/Tablet 管理、Compaction、Trash、Repair 和异步物化视图 Job。

审查重点：

- 表模型约束。
- 分区和分布的不可变性。
- 索引构建和重写成本。
- 物化视图一致性和刷新行为。
- CREATE、SELECT、ALTER、LOAD、管理类操作等所需权限。

### 会话、统计信息与查询

包括 `SELECT`、`EXPLAIN`、会话变量、进程/查询/Profile 控制、`ANALYZE`、统计信息显示/删除和 Plan Replay。

审查重点：

- 作用域是会话、全局还是配置文件。
- 变更是否持久化。
- 如何验证效果。
- 对 CBO/统计信息的影响。

## 基础元素

### 数据类型

数据类型文档应说明：

- 存储和取值范围。
- 字面量格式。
- Cast 和比较行为。
- NULL/默认值行为。
- 是否允许用于 Key、分区、索引、生成列或外部映射。
- 复杂类型的差异：ARRAY、MAP、STRUCT、JSON、VARIANT、BITMAP、HLL、QUANTILE State、IP 和空间类型。

### 操作符

操作符文档应覆盖优先级、操作数类型、返回类型、NULL 行为和示例。对逻辑和比较操作符，适用时应包含三值逻辑。

## 示例要求

好的示例应：

- 当语句需要表、Catalog 或用户时，从最小对象准备开始。
- 包含一个正常场景和至少一个边界或特殊场景。
- 对函数和查询，在 `text` 代码块中展示预期输出。
- 除非页面明确覆盖该外部集成，否则避免依赖未说明的外部服务。
- 使用确定性值；除非示例本身解释时间行为，否则避免使用当前时间。

## NULL 与错误行为

始终检查：

- NULL 是传播、被忽略，还是产生默认值？
- 是否存在 `or_null` 或 `or_default` 变体？
- 非法输入会报错、返回 NULL，还是返回默认值？
- 空数组、空字符串、空 Map 与 NULL 是否不同？
- 类型转换是隐式还是显式？
