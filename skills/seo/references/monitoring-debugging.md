# 监控与调试参考

覆盖 Search Console、流量下降排查、搜索运算符、安全监控、Google 趋势。

## 1. Search Console 核心工作流

### 1.1 初始设置

1. 验证网站所有权（必需，否则无法获取数据）
2. 提交站点地图（非必须但推荐）
3. 定期检查：Google 发现问题会发送邮件；建议每月或每次网站变更时检查

### 1.2 关键报告

| 报告 | 面向人群 | 用途 |
|------|---------|------|
| **效果** | SEO/营销 | 展示次数、点击次数、CTR、平均排名趋势 |
| **网页索引编制** | 开发者 | 索引状态、错误原因、排除的页面 |
| **网址检查工具** | 开发者 | 单个 URL 的索引状态、抓取结果、渲染快照 |
| **抓取统计信息** | 开发者 | Googlebot 访问频率、主机状态、抓取错误 |
| **富媒体搜索结果** | 两者 | 结构化数据错误/警告/有效项目数 |
| **核心网页指标** | 开发者 | Core Web Vitals 达标情况（按 URL 分组） |
| **人工处置措施** | SEO/营销 | 是否受到人工惩罚 |
| **安全问题** | 开发者 | 恶意软件、钓鱼、被黑检测 |
| **移除工具** | 两者 | 紧急从搜索结果中移除内容（约 6 个月有效） |
| **地址更改** | 两者 | 迁移网站时告知 Google |

### 1.3 气泡图分析框架

在 Looker Studio 中构建：Y 轴 = 平均排名（倒序），X 轴 = CTR，气泡大小 = 点击次数。

| 象限 | 含义 | 行动 |
|------|------|------|
| 高排名 + 高 CTR | 表现正常 | 无需操作 |
| 低排名 + 高 CTR | 用户想找到你但排名不够 | **重点优化**这些查询 |
| 高排名 + 低 CTR | 标题/描述不吸引用户或用户已直接找到答案 | 优化标题和描述 |
| 低排名 + 低 CTR | 区分是否相关 | 相关→优化，不相关→调整策略 |

### 1.4 Search Console + Google Analytics 联合分析

| 工具 | 数据层面 | 关键指标 |
|------|---------|---------|
| Search Console | 搜索前（搜索结果页面） | 展示、点击、CTR、查询 |
| Google Analytics | 搜索后（网站内交互） | 会话、停留时长、转化、回访率 |

数据差异的常见原因：
- GA 代码缺失或配置错误
- Cookie 跟踪拒绝
- 时区不一致（SC 默认太平洋时间）
- 归因模型差异
- SC 仅统计规范 URL
- SC 包含 PDF 等非 HTML，GA 默认不包含

## 2. 搜索流量下降排查

### 2.1 下降原因速查

| 原因 | 特征 | 如何确认 |
|------|------|---------|
| **算法更新**（核心/垃圾） | 排名大幅或小幅下降 | 检查[搜索状态信息中心](https://status.search.google.com/) |
| **技术问题** | 服务器错误、robots.txt 误配、noindex 误用 | "抓取统计信息"+"网页索引编制"报告 |
| **安全问题** | 恶意软件/钓鱼 → 浏览器警告 | "安全问题"报告 |
| **网络垃圾** | 违反政策 → 人工或自动处置 | "人工处置措施"报告 |
| **季节性/兴趣** | 随季节或趋势同步波动 | Google 趋势对比 |
| **网站迁移** | 改版后排名波动 | 参考迁移故障排查 |

### 2.2 分析步骤

1. **扩展时间范围至 16 个月** → 观察年同比规律，排除季节性
2. **比较完整周期** → 过去 3 个月 vs 前一周期或去年同期（排除更新进行中的数据混乱）
3. **按搜索类型拆分** → 网页、图片、视频、新闻分别查看
4. **关注平均排名** → 持续下降→内容自评；排名稳定但流量降→可能是搜索兴趣变化
5. **找到规律** → 按"点击次数差值"排序受影响的页面；区分全站降 vs 部分页面降
6. **Google 趋势做行业基准** → 判断是行业趋势还是自身问题

### 2.3 核心更新应对

- **不要做快速修复** — 没有快速修复
- 内容改进可能需要**几个月**才能体现
- 删除内容应该是**最后手段**
- 小幅下降（第 2→第 4 位）不需采取重大行动
- 大幅下降（第 4→第 29 位）→ 全面的全站自我评估
- 不以删除"不利于 SEO"的元素为策略

### 2.4 算法更新的数据对比方法

1. 确认更新已开始和已完成（搜索状态信息中心）
2. 更新完成后再等待**至少一整周**才做分析
3. 将更新完成后的一整周，与更新开始前的一整周对比
4. 不要用更新期间的数据做 baseline

## 3. 搜索运算符调试

| 运算符 | 用途 | 示例 |
|--------|------|------|
| `site:example.com` | 查看已索引的页面（不穷尽） | 粗略了解索引量 |
| `site:example.com keyword` | 查找包含特定词的已索引页面 | 发现是否有关键词堆砌 |
| `site:example.com viagra casino` | 检测垃圾内容 | 安全监控 |
| `filetype:pdf site:example.com` | 查找特定文件类型 | 检查是否有敏感 PDF 被索引 |
| `imagesize:1200x800 site:example.com` | 图片搜索：查找特定尺寸 | 检查图片使用 |
| `src:https://example.com/img.jpg` | 查找引用特定图片的页面 | 发现热链接 |

**限制**：`site:` 运算符结果不完整，不排名时不保证显示。更可靠的工具是 Search Console 网址检查工具。

## 4. 安全监控

### 4.1 用户生成垃圾预防

1. 发布明确的滥用防范政策
2. 建立用户声望系统和审核流程
3. 新用户/低声望用户帖子使用 noindex，获得声望后再索引
4. 对不受信任内容的链接加 `nofollow` 或 `ugc`
5. 使用 reCAPTCHA 防自动注册
6. 用 `site:` 搜索 + Google 快讯持续监控异常内容

### 4.2 恶意软件预防清单

**所有网站所有者：**
- [ ] 使用安全密码
- [ ] 谨慎选择第三方内容提供商
- [ ] 联系托管公司获取安全支持
- [ ] 确保本地工作站安全（防病毒、最新补丁）

**有服务器访问权限的：**
- [ ] 检查服务器配置安全
- [ ] 备份并保护 .htaccess 文件
- [ ] 及时更新所有软件和补丁
- [ ] 监控日志异常（`=http:` 或 `=//` 参数、异常流量走缓）
- [ ] 检查 XSS 和 SQL 注入漏洞
- [ ] 使用 SSH/SFTP 替代 telnet/FTP

### 4.3 被黑/恶意软件恢复流程

1. 在 Search Console 检查是否有新增可疑所有者
2. 查看"安全问题"报告中的示例 URL
3. 移除恶意内容（包括第三方资源中的）
4. 修复安全漏洞
5. 提交审核请求

### 4.4 社会工程学（钓鱼/欺骗）

特征：伪装成可信实体诱使用户执行危险操作。

排查：
1. 检查所有页面（包括第三方嵌入内容、广告、图片来源）
2. 第三方服务必须明确显示品牌和关系
3. 移除欺骗性内容后提交审核

### 4.5 屡次违规

- 短时间内反复违规 → 被标记为"屡次违规网站"
- 状态持续 30 天，期间不能请求审核
- 通过邮件通知

## 5. Google 趋势使用场景

| 场景 | 方法 |
|------|------|
| 发现上升趋势 | 探索工具 → 查看搜索热度时间轴和"搜索量上升"的相关查询 |
| 关键字研究 | 结合 Search Console 效果报告的查询数据，交叉验证趋势 |
| 季节性内容规划 | 查看历史数据找出季节规律，提前发布内容 |
| 行业基准比较 | 判断流量波动是行业现象还是自身问题 |
| 品牌认知分析 | 监控用户搜索品牌时的相关词语 |

操作步骤（关键字研究）：
1. 添加最多 5 个关键字
2. 查看搜索热度时间轴
3. 查看多国家/地区分布
4. 查看"相关主题"和"相关查询"（热门 + 搜索量上升）
5. 检查其他语言的相关主题
6. 确认与网站相关后再投入

## 6. CMS 特定调试

Google 对 CMS 平台（如 Drupal、WordPress）有特定调试建议：
- 查看 Google 发布的具体 CMS 调试指南
- Search Console 的"网页索引编制"报告中平台特定模式需要特殊处理

## 7. 监控频率建议

| 频率 | 操作 |
|------|------|
| 每次网站变更后 | 查看"网页索引编制"报告 |
| 每月 | 例行检查效果报告、"网页索引编制"报告、富媒体搜索结果报告 |
| 持续 | Google 会通过邮件通知关键问题（人工处置、安全问题） |
| 每次 Google 更新后 | 等待更新完成 + 一周后分析效果报告 |
